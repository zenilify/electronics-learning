# Python tooling for the electronics-learning journey.
#
# The goal of this repo is hobby electronics: learning dev boards, sensors,
# soldering, and configuring ESP32 boards to build sensors that report to
# Home Assistant.
#
# ESPHome is the star here: it turns a small YAML file into ESP32/ESP8266
# firmware that talks to Home Assistant natively. Configs can be validated
# and compiled on any computer (no board attached needed), which makes it a
# great learning + CI tool.
#
# Install into the project venv:
#   python3 -m venv .venv
#   . .venv/bin/activate
#   pip install -r requirements.txt
#
# ESPHome pulls in its own dependencies (platformio, esptool, pyserial, ...).
esphome==2026.7.4
