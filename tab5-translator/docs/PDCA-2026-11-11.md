## 2 · Measurements and findings

### 2.0 Baseline tools

- **Console without reset.** `tools/console.py` (pyserial) reboots the Tab5 on every use. `tools/console_nr.py` opens the port with
  plain `os.open` + termios, never writes DTR/RTS and clears HUPCL. Measured: log timestamps keep counting across three sessions
  (3 097 s → 3 109 s → 3 113 s), so the board did not restart. This is what makes a 24 h `zfix` watch possible at all.
- **`flash.sh backup` was not a backup.** It keeps segments in one fixed folder and skips the ones already there. The 7 Nov run
  stopped at segment 1; 14 old segments were still in place, so a later run would have glued old and new flash together.
  `tools/backup_full.sh` reads into a fresh folder per run and writes `full.bin` only when all 16 segments are there.

### 2.1 USB-A port (cycle 1)

- **Cause 1 — the 5 V switch was never on.** The Espressif BSP only raises `USB5V_EN` inside `bsp_usb_host_start()`; PAPP never
  called it. After the driver's chip reset all expander pins are "output, high-Z, pull-down", i.e. the switch input sits low.
- **Cause 2 — camera and Tab5 on different networks.** The XIAO joins the strongest SSID it knows; on the bench that is the travel
  router `kaizen-tr` (−31 dBm). The Tab5 was pinned to the home Wi-Fi (`wifi0 [picked]`, kept there for the remotes bench).
  mDNS does not cross the travel router, so even a powered camera was "not found". Measured: `_pappcam._tcp` absent from cachy's
  LAN (avahi positive control: 271 other services seen); after `wifi 2` the Tab5 logged `back camera: http://192.168.29.246:80`.
  Left the Tab5 on `kaizen-tr` with the picker on **Auto** (was: pinned to wifi0). Remotes still linked (stick 4 s, dial 4 s),
  cachy still reached through the router (`probe LAN -> 200 (16 ms)`). Revert: console `wifi 0`.
- **Expander read-back, both chips** (console `io`, fw 0.4.1):
  `0x43 dir=ef out=22 hiz=dd pull_en=ff pull_sel=10 in=10` · `0x44 dir=ff out=09 hiz=f6 pull_en=ff pull_sel=00 in=00`
  - 0x43 pin 0 (antenna select) is **high-Z**: `net.c` sets direction and level but never push-pull, so `ant ext` cannot
    switch to the external antenna. Fixed in cycle 2.
  - 0x43 pin 2 (`EXT5V_EN`, Grove / M5-Bus 5 V) and 0x44 pin 7 (`CHG_EN`) are not driven by PAPP. Battery current reads
    0.00 A at 8.14 V on USB power — see §4.
- USB host stack: installs and enumerates on this unit (P4 rev 1.3); internal RAM 333 → 322 kB. Started by console only
  (`usb host once`) in this cycle.
